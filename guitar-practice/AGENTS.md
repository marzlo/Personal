# 指間：吉他練習 APP

- 先讀 `PROJECT_CONTEXT.md`。這是與拾頁分開的獨立 APP；不要修改上層首頁、Podcast 或既有 localStorage。
- 使用繁體中文。`src/` 是可編輯來源；根目錄 HTML 為可直接開啟的獨立匯出頁。
- `src/harmony.html` 是最新級數配和弦設計；調式支援大調、自然小調、和聲小調、爵士旋律小調。
- 不要把「音階內所有音」解釋成一定適合任意旋律。區分調內和弦、含調外音的色彩選擇。
- 保留原圖庫作者標示；不要擅自把圖庫當成可自由散布的原創素材。
- 驗證：`node tests/harmony.cjs`、`node tests/package.cjs`。
